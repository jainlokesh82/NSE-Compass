NSE STOCK ANALYSIS PORTAL - MOBILE PWA

This package must be hosted. Do not open index.html directly on a phone.

Deployment:
1. Upload all files and the api folder to the root of a GitHub repository.
2. Import the repository into Vercel and deploy with default settings.
3. Open the resulting HTTPS website on Android Chrome or iPhone Safari.
4. Android: browser menu > Add to Home screen / Install app.
5. iPhone: Share > Add to Home Screen.

For live investment research, keep Demo mode off. Review the Data Sources tab and independently verify the current price, results, announcements and corporate actions on NSE/company filings and the broker terminal.

Coverage note:
The application accepts valid NSE symbols, but complete analysis depends on upstream provider mapping and data availability. Some series, SME securities, recent listings, renamed symbols, suspended securities, ETFs, REITs and InvITs may not have the same data coverage as ordinary EQ-series equities.
